 I am building the basic prototype of a platform called Mahdi which will match renters and landlords with their desired property or tenant based on semantic searches and a database that will be populated with the information users provide in initial onboarding calls and update context about the user throughout their user journey. 

I have been learning machine learning and how to use langchain and LLMs in the WatAI workshops at my university so I would like to use these concepts too. 

Features:

1. Onboarding call that will give context of what the user is looking for with the most granular details. 

2. An agent to match renters and tenants using information about their nice to haves and non-negotiables. 

3. It should also be able to negotiate and carry out two-way conversations between the prospective landlords and tenants based on the context after asking a simple yes-or-no to the user so the user doesn't have to put in the work and repeat themselves repeatedly. 

4. The main objective of the AI would be to schedule a showing between the two parties and then the user will decide if they want to go forward with it or not and if they found another contraint / requirement in their search, the AI will pick up on that. 

The possibilities of features are endless but this is the basic, main, base. 

5. The platform should also enable people to pay for rent when they find a suitable place / tenant.
